# 固定支出为什么决定自由程度

零碎消费当然会影响现金流，但真正决定一个人能否长期降低劳动强度的，往往是住房、医疗、交通、赡养和教育等大型持续性支出。

如果一项开支每年稳定增加 2 万元，而你希望通过资产覆盖它，那么按 3.5% 的提款率计算，需要额外约：

\[
\frac{20000}{0.035}\approx571429
\]

也就是说，一个“每月多花一点”的长期生活选择，可能对应几十万元甚至上百万元的资产需求。

## 关键问题

不要只问“这个东西贵不贵”，而要问：

> 它会不会永久提高我的生活基线？
