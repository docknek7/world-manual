# THE WORLD MANUAL

我试图理解现代社会是怎样运行的，以及一个普通人如何尽可能自由地生活。

这个网站不是新闻收藏夹，也不是按日期排列的博客，而是一份长期修订的个人“世界模型”。我会把自己真正想明白的问题放进来：财富怎样换成时间，国家怎样运转，产业为什么有高低附加值，金融系统怎样影响普通人的生活，以及一个人怎样建立不完全依赖工资的生活。

## Current Questions

- 为什么高生产率并不一定带来同等幅度的工资增长？
- 一个人真正需要多少资本，才能让“工作”从必须变成可选？
- 为什么有些国家拥有强制造业，却未必拥有最高的人均收入？
- 全球价值链里，利润究竟被谁获得？
- 自动化会减少总劳动时间，还是只会改变劳动结构？
- 一个社会的住房、医疗、教育制度如何改变个人财务自由的门槛？

## 使用方法

建议不要把“看过什么”机械记录进来，而是围绕问题写。每篇内容最好同时回答三个层次：

1. **事实是什么？**
2. **机制是什么？**
3. **这件事会如何影响国家、企业或个人？**
