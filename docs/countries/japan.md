# 日本研究模板

## 想回答的问题

- 为什么日本长期低增长，但社会基础设施和生活质量仍然较高？
- 日本制造业在全球价值链中处于什么位置？
- 日本为何长期拥有庞大的海外资产？
- 实际工资为什么长期增长缓慢？
- 老龄化如何影响财政和劳动市场？

## 建议数据

- 人口年龄结构
- 名义与实际 GDP
- 人均 GDP
- 每小时劳动生产率
- 经常账户余额
- 净国际投资头寸
- 制造业增加值
- 政府债务
- 实际工资
- 房价指数

## 写作原则

先列数据，再解释机制，最后写自己的判断。不要先有结论，再去寻找支持材料。
