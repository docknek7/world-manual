# GDP、GNI 与生产率

## GDP

GDP 衡量一个经济体境内生产的最终商品和服务价值。

\[
Y=C+I+G+NX
\]

这个恒等式本身不是因果模型，而是一种国民账户分解。

## GNI

GNI 更强调“本国居民获得的收入”。当一个国家存在大量跨境资本收入时，GDP 与 GNI 之间可能出现明显差异。

## 生产率

长期生活水平最值得观察的变量之一，是单位劳动投入创造多少增加值。

需要进一步区分：

- 每名劳动者产出
- 每小时劳动产出
- 全要素生产率
- 行业生产率

## 尚未解决的问题

- 为什么生产率增长不一定同步转化为工资增长？
- 生产率、劳动份额和资本回报率之间如何联系？
