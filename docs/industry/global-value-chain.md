# 全球价值链

## 一句话结论

出口额并不等于一个国家真正获得的价值。

一个产品可能在多个国家之间流转：原料、零部件、设计、组装、物流、营销和零售都可能分布在不同经济体。

## 简化例子

假设某产品最终出口价格为 350：

- 进口芯片：100
- 进口屏幕：50
- 进口电池：30
- 其他进口部件：100
- 本地增加值：70

那么总出口额是 350，但本地真正新增的价值只有 70。

\[
\text{Domestic Value Added}
=
\text{Gross Exports}
-
\text{Imported Inputs}
\]
